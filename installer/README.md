# Установщик Sintet

`Release/Sintet-Setup.exe` устанавливает лаунчер на Windows 10/11 x64. Он позволяет выбрать папку, создать ярлыки и удалить лаунчер через параметры Windows. Если WebView2 отсутствует, установщик запускает подписанный Microsoft загрузчик.

Для сборки используй те же инструменты, что и для лаунчера, и запусти из корня репозитория:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File installer/build.ps1
```

Установщик включает проверку подписи обновлений. Последующие стабильные версии поступают через встроенное автообновление Sintet.
