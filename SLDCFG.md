# Оформления Sintet (.sldcfg)

В лаунчере: **Мастерская → Моё → Оформления → Импорт .sldcfg**. Оформление добавляется в список; включается отдельно.

Для своей темы нажми **Экспорт .sldcfg** и выбери место сохранения. Сервис автоматически проверит настройки, фон, шрифт и иконку, подпишет пакет и вернёт готовый файл. Его можно отправить другу. Для первого экспорта нужен вход в Sintet ID и доступ к sintet.xyz. Подписанный пакет сохранённого слота кэшируется для повторного экспорта. Для онлайн-обмена действует ограничение 4 МБ на файл.

Готовый подписанный файл можно загрузить на сайт вручную. Кнопка **В кабинет** в лаунчере автоматически проверяет, подписывает и сохраняет тему в библиотеку аккаунта. В лаунчере **Из кабинета** показывает доступные подписанные темы. После изменения настроек при следующем экспорте подпись создаётся автоматически заново. Опубликованный сайт хранит библиотеку в R2. Для разработки можно явно задать SINTET_LOCAL_THEME_SYNC=1 и использовать локальный кабинет на порту 3033.

Для подписи проверенной темы используй PowerShell:

```powershell
& "$env:LOCALAPPDATA\SintetSigning\sldcfg.exe" pack -name "Моя тема" -out "$env:USERPROFILE\Downloads\sintet-theme.sldcfg"
```

Параметры `-background`, `-icon` и `-font` добавляют проверенные ресурсы. Утилита преобразует статичные PNG или JPEG в PNG. Из шрифтов формат принимает TrueType. `-appearance` позволяет взять параметры из сохранённых настроек самого лаунчера; файлы фона и шрифта при этом нужно указать явно. Видео и анимированные GIF остаются доступны для локального оформления.

Ключ подписи хранится в серверном секрете Vercel. Для локального сервиса используется копия под защитой Windows DPAPI. Подпись подтверждает прохождение автоматической проверки формата. Лаунчер дополнительно проверяет подпись и содержимое полученного пакета.

Версия 1: `SLD1`, номер версии (u16), подпись Ed25519, длина (u32), один поток gzip. Подпись покрывает заголовок без поля подписи и сжатые данные. Внутри – поля фиксированного набора и до трёх ресурсов без путей. Лимиты: фон 12 МиБ, шрифт 4 МиБ, иконка 512 КиБ.
